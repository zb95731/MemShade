# 照片管理工具设计文档

## 1. 项目概述

### 1.1 项目背景
开发一款Windows桌面照片管理工具，支持从多种来源（SD卡、安卓手机、iOS设备、本地文件夹）导入照片，并自动按主题、日期、设备类型、文件类型进行分类整理。

### 1.2 核心目标
- 简化照片导入流程
- 智能分类整理，提升查找效率
- 支持自定义文件夹结构和文件名
- 提供重复照片检测和预览功能

### 1.3 目标用户
- 个人用户：整理手机、相机中的日常照片
- 摄影师：管理大量摄影素材，按项目/主题分类
- 家庭用户：整理多年积累的照片档案

## 2. 功能需求

### 2.1 来源导入模块

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| SD卡导入 | 自动检测SD卡并列出可导入文件 | 高 |
| 安卓手机导入 | 支持MTP协议连接安卓设备 | 高 |
| iOS设备导入 | 支持通过文件共享导入照片 | 中 |
| 本地文件夹导入 | 支持选择本地任意文件夹 | 高 |
| 重复导入检测 | 通过文件哈希检测已导入文件并提示 | 高 |

### 2.2 智能分类模块

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 主题分类 | 用户自定义主题名称 | 高 |
| 日期分类 | 按年份/日期自动分组 | 高 |
| 设备类型分类 | 按相机、手机、360相机等分组 | 高 |
| 文件类型分类 | 按照片、视频分组 | 高 |
| 自定义文件夹结构 | 支持主题+日期作为一级目录 | 高 |

**文件夹结构示例：**
```
photo/
└── 2025年/
    └── 20250529_千岛湖湖心谷/
        ├── 360/
        ├── 富士视频/
        └── 富士照片/
```

### 2.3 照片预览模块

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 缩略图网格 | 快速浏览待处理照片 | 高 |
| 大图预览 | 点击查看大图 | 高 |
| 旋转操作 | 支持顺时针/逆时针旋转 | 中 |
| 缩放操作 | 支持缩放查看 | 中 |

### 2.4 重复照片检测模块

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 哈希比对 | 基于文件内容哈希检测重复 | 高 |
| 手动选择保留 | 列出重复组，用户手动选择保留 | 高 |

### 2.5 导出模块

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 自定义导出路径 | 支持选择任意本地目录 | 高 |
| 文件名模板 | 提供预设模板如 `{日期}_{设备}_{序号}` | 高 |
| 批量导出 | 支持选择部分或全部导出 | 高 |

## 3. 界面设计

### 3.1 整体布局

采用单窗口一站式体验设计：

```
┌─────────────────────────────────────────────────────────────┐
│                    主窗口（单窗口设计）                       │
├──────────────┬──────────────────────────────────────────────┤
│  左侧面板     │              右侧主区域                        │
│  ┌─────────┐ │  ┌──────────────────────────────────────┐   │
│  │ 来源选择 │ │  │           顶部工具栏                   │   │
│  │(SD卡/手机)│ │  │ 预览模式 │ 分类规则 │ 导出设置      │   │
│  ├─────────┤ │  ├──────────────────────────────────────┤   │
│  │ 文件列表 │ │  │           中间预览区                   │   │
│  │(待处理)  │ │  │  [照片缩略图网格/大图预览]            │   │
│  ├─────────┤ │  │  [选中照片高亮显示]                    │   │
│  │ 分类结果 │ │  ├──────────────────────────────────────┤   │
│  │(树形结构) │ │  │           底部状态栏                   │   │
│  └─────────┘ │  │ 已选: X | 总数: Y | 重复: Z           │   │
└──────────────┴──────────────────────────────────────────────┘
```

### 3.2 左侧面板

| 区域 | 功能 |
|------|------|
| 来源选择区 | 显示可导入设备列表（SD卡、手机、本地文件夹） |
| 文件列表区 | 显示待处理的照片文件列表 |
| 分类结果区 | 显示当前分类结构的树形预览 |

### 3.3 右侧主区域

| 区域 | 功能 |
|------|------|
| 顶部工具栏 | 切换预览模式、配置分类规则、设置导出选项 |
| 中间预览区 | 缩略图网格或大图预览，支持选中高亮 |
| 底部状态栏 | 显示选中数量、总数、重复数量等统计信息 |

## 4. 技术架构

### 4.1 技术栈

| 层级 | 技术 | 职责 |
|------|------|------|
| 前端框架 | Vue 3 + TypeScript | UI展示、用户交互 |
| 样式 | TailwindCSS 3 | 响应式布局 |
| 后端 | Tauri + Rust | 文件IO、照片处理、哈希计算 |
| 数据库 | SQLite | 存储导入记录（用于重复检测） |
| 图标 | Lucide Icons | 界面图标 |

### 4.2 核心数据结构

```typescript
interface PhotoItem {
  id: string;
  path: string;
  fileName: string;
  fileSize: number;
  hash: string;        // 文件哈希值，用于重复检测
  exif: {
    date: string;      // 拍摄日期
    device: string;    // 设备类型
    width: number;
    height: number;
  };
  category: {
    theme: string;
    date: string;
    deviceType: string;
    fileType: string;
  };
  isSelected: boolean;
  isDuplicate: boolean;
  duplicateGroupId: string | null;
}

interface ImportRecord {
  id: string;
  fileName: string;
  hash: string;
  importTime: string;
  exportPath: string;
}
```

### 4.3 核心业务流程

```
用户选择来源 → 扫描文件 → 计算哈希 → 检测重复 → 显示预览
    ↓
用户配置分类规则 → 自动分类 → 用户微调 → 确认导出
    ↓
选择导出路径 → 复制文件到目标位置 → 更新导入记录
```

## 5. 安全性考虑

| 风险点 | 应对措施 |
|--------|----------|
| 文件操作权限 | 使用Tauri提供的安全API，避免直接系统调用 |
| 路径遍历攻击 | 对用户输入路径进行严格校验 |
| 敏感信息泄露 | 不存储用户照片内容，仅存储哈希和路径 |
| 数据备份 | 提供导入记录导出功能 |

---

## 6. 性能考虑

| 优化点 | 策略 |
|--------|------|
| 大量照片处理 | 使用Rust多线程并行处理 |
| 预览性能 | 生成缩略图缓存，避免重复解码 |
| 哈希计算 | 使用高效哈希算法，大文件分块计算 |
